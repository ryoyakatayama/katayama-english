# 片山英単語 ― カレンダー・毎日の目標対応版

## 起動と更新

Windows 10／11（x64）用です。ZIPをすべて展開し、`片山英単語.exe` を開きます。
Pythonのインストール・管理者権限・ネット接続は不要です。
他のPCには `_internal` を含むフォルダー全体をコピーしてください。

**旧版の記録を引き継ぐ場合：** 旧版と新版を終了し、旧版の `data` フォルダーを
新版の `片山英単語.exe` と同じ場所へコピーしてから起動してください。
既存の `learning.sqlite3` と `settings.json` をそのまま読み込みます。
旧版の記録もカレンダーに表示します。配布ZIPには学習履歴を含めていません。

## 1日の目標とワンクリック学習

開始画面上部の「目標を変更」で1〜2,000語を設定できます。初期値は20語です。
目標は保存され、次の日・次回の起動にも引き継ぎます。
今日の学習語数、目標に対する割合、残り語数、達成バーを表示します。
目標を達成するとお祝いのメッセージになります。達成後も学習を続けられます。
割合の表示は100%まで、語数の表示は目標を超えても増えます。

「目標の○問をはじめる」を押すだけで、目標数ちょうどの問題を開始します。
このボタンは下のチェックボックスで選択した範囲と制限時間を使用します。
通常コースの問題数やモードとは独立して動き、その設定を変更しません。

- 今日まだ回答していない単語を優先します。
- 1コース内では同じ単語を重複させません。
- 目標が20語なら、毎回20問を出します。残り語数だけを出す方式ではありません。
- 未回答の語が足りない場合は、今日すでに回答した語も含めて目標数にします。
  その場合、日別学習語数が問題数と同じだけ増えるとは限りません。
- 選択範囲が目標数より少ない場合は、範囲を増やすか目標を下げてください。
- 同じ単語に別の日に取り組むことも、その日の目標にカウントします。

「連続○日」は、1語以上に取り組んだ日が連続した日数です。目標達成日数ではありません。
今日まだ学習していなくても、昨日まで続いていればその日数を表示します。
日付が変わると、その日の語数・達成度を集計し直します（画面は約30秒以内に更新）。

## 学習カレンダー

開始画面の「学習記録」から開きます。左右の矢印で前月・翌月、「今月へ」で戻れます。
各日付にその日の学習語数を表示します。日付を押すと、その日の語数・回答回数・正答率を表示します。
学習した日は色が付き、今日の日付には青い枠が付きます。

| 表示 | 数え方 |
|---|---|
| 日別学習語数・今日の達成度 | 同じ日の同じ単語は、何度回答しても1語 |
| 月の学習語数（日別の合計） | 各日の学習語数を合計。別の日に復習した語は再び加算 |
| 月内の重複を除く語数 | 同じ月の同じ単語は1語 |
| 回答回数 | 同じ単語への再回答もすべて数える |
| 正答率 | 正解した回答数 ÷ 全回答数 |

例：月曜日に apple を3回答、火曜日に apple と book を各1回答した場合、
月曜日1語、火曜日2語、月の日別合計3語、月内重複なし2語、回答回数5回です。
正解・不正解・時間切れを学習として数え、回答前に終了した問題は数えません。
集計の日付はPCのローカル時刻です。履歴には実際の回答時刻を保存しています。

カレンダーの下に、従来のコース別進捗と最近10回の学習記録があります。
画面に収まらない部分はマウスホイールまたは右側のスクロールバーで見られます。

## 通常の学習

基礎・応用・上級Ⅰ・上級Ⅱの4コース、各500語の計2,000語を収録しています。
出題範囲は複数選択できます。各コースの内訳は名詞200・動詞150・形容詞120・副詞30語です。
英語→日本語の6択は同じ品詞でそろえ、同じ訳や登録された類義語グループの混在を避けます。
同一起動中の再出題では選択肢の顔ぶれも変わります。

通常トレーニングは1〜対象語数（最大2,000問）、制限時間は1問3〜120秒です。
ランダム・苦手優先・未学習のみ・復習日が来た単語の4モードを選べます。
正解後の次回復習は連続正解数に応じて1・3・7・14・30・60日後、不正解なら10分後です。
結果画面で、今回の間違いだけの復習もできます。

数字キー1〜6で回答、回答後のEnterで次へ進めます。Tabで移動し、Spaceでボタンやチェックを操作できます。
別アプリを見ている間もタイマーは進みます。回答確認中は止まります。
途中終了しても回答済みの履歴は保存されます。中断位置からの再開はできません。

単語とレベルは本アプリ独自の編集です。TOEIC公式の語彙順位ではありません。
各単語の代表的な意味を1つ学習する方式で、全ての意味・用法を網羅する辞書ではありません。

## 保存場所

- `data/learning.sqlite3`：回答履歴、単語別成績、復習時刻
- `data/settings.json`：出題範囲、モード、問題数、秒数、1日の目標

アプリを終了してから `data` をコピーすると、記録と目標をまとめて引き継げます。
書き込み不可・DBを開けない場合は開始画面に表示し、その起動中のみ履歴を保持します。
既存DBを削除して修復する処理はありません。書き込み可能な場所で使ってください。

## ソース版

別添の `片山英単語-source.zip` には編集可能なPythonコードを収録しています。
Python 3.10以降とTkinterで `python app.py` を実行してください。

```sh
python -m unittest -v
python app.py --self-test test-report.json
```

`engine.py` が出題、`progress.py` が保存と日別・月別集計、`app.py` が画面です。
`vocabulary*.txt` が2,000語のデータ、`synonyms.txt` が類義語の除外グループです。
Windows配布版は同梱の `build_windows.cmd` でビルドできます。ビルド時のみPyInstallerが必要です。
